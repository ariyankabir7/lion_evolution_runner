# Audio

All audio is currently **synthesised in code** by `tools/generate_audio.py` (numpy + ffmpeg → OGG), so
the game has full sound without any third-party files. Every sound can be swapped for a recorded one
without touching Dart code.

## Swapping in a real file

1. Convert it to OGG (mono is fine): `ffmpeg -i in.wav -c:a libvorbis -q:a 4 out.ogg`
2. Save it as `assets/audio/sfx/<name>.ogg` (or `assets/audio/music/run_loop.ogg`), overwriting the
   generated file.
3. If it's too loud or quiet, adjust `volume` for that entry in `Sfx` (`lib/core/services/audio_service.dart`).

`generate_audio.py` never overwrites existing files unless run with `--force`, so dropped-in audio is safe.
Add each file you use to the credits table below (CC0 needs no credit, but it's good practice).

## Recommended CC0 replacements

All packs below are **CC0** (public domain). Kenney packs: <https://kenney.nl/assets> · OpenGameArt: <https://opengameart.org>.
Filenames are the ones inside each pack; "listen for" means pick by ear from that group.
